# Inventory Management System

## Project Overview

Inventory Management System is a desktop-based application developed using Java. The system will help manage products, categories, suppliers, purchases, sales, and inventory stock.

The project focuses on applying appropriate **Design Patterns**, maintaining clean software architecture, and developing a maintainable and extensible application.

## Technologies

* Java
* JavaFX
* Maven
* SQLite
* JDBC
* Git & GitHub

## Planned Features

* Product Management
* Category Management
* Supplier Management
* Purchase / Stock In
* Sales / Stock Out
* Inventory Management
* Search and Reports

## Design Patterns

Design Patterns will be selected and implemented based on actual design requirements and business problems.
